# Finnbot glossary

The terms, abbreviations, and indicators in the Finnbot digest email, how to read them, and how its swing and long-term ideas are picked: <https://andresc44.github.io/finnbot-glossary/>.

`index.html` is generated from `src/digest/glossary.py` in the (private) Finnbot repo and pushed by its digest runs (`src/digest/glossary_page.py`). Edit the glossary there, not here.
